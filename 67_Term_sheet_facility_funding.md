# Term Sheet, Facility & Funding Statuses

→ Back to [Credit Facilities Overview](16_Credit_Facilities_Overview.md) · [Term Sheet Workflow](18_Term_Sheet_Workflow.md)

## Phase 1 — Term Sheet

| Status | Meaning |
|---|---|
| **Draft** | Created; editable |
| **Signed** | Borrower signed; ready to submit |
| **In review** | Waiting for facility agent |
| **Accepted** | Approved; facility created automatically |
| **Rejected** | Declined; create a new term sheet |
| **Changes Requested** | Borrower edits, re-signs, and resubmits |

**Flow:** Borrower creates → signs (Adobe Sign) → submits → facility agent approves → facility created automatically

## Phase 2 — Facility (Master Commitment)

| Status | Meaning |
|---|---|
| **Draft** | Facility agent is setting up the facility |
| **Pending** | Waiting for lender review and signature |
| **Active** | At least one lender approved; facility can be used |

| Facility Setup Status | Borrower can request funding? |
|---|---|
| **In Progress** | No |
| **Completed** | Yes |

**Flow:** Term sheet accepted → facility agent configures and adds lenders → submits → lender approves & signs → **Active** → deal modelling → completed

## Phase 3 — Funding

| Status | Meaning |
|---|---|
| **Draft** | Funding request created; editable |
| **In review** | Waiting for facility agent |
| **Approved** | Approved; funding notice created automatically |
| **Rejected** | Declined; create a new request |
| **Changes Requested** | Borrower edits and resubmits |

**Flow:** Borrower maps loans → creates funding request → submits → facility agent approves → funding notice created → facility agent approves notice → signs for each lender → each lender reviews, transfers funds, Confirm and Settle

## Complete End-to-End Flow

```
1. Borrower: Create and sign term sheet
2. Borrower: Submit to facility agent
3. Facility agent: Approve → facility (master commitment) created
4. Facility agent: Configure facility, add lenders, submit
5. Lender: Review and sign → facility becomes Active
6. Facility agent: Complete deal modelling
7. Borrower: Map loans → create funding request → submit
8. Facility agent: Approve funding request → funding notice created
9. Facility agent: Approve notice → sign for each lender
10. Lender: Review notice, transfer funds → Confirm and Settle
```

## Key Points

- The facility does not exist until the term sheet is accepted
- Funding cannot start until facility is **Active** and setup is **Completed**
- **One lender's approval** activates the facility
- Approved funding request and accepted term sheet both create the next item automatically
- An active facility can support multiple funding requests over its life

> Asset Sale deals follow a different status path. See [Asset Sale Statuses](70_Asset_Sale_Statuses.md).
