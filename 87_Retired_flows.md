# Retired Flows

## Overview

This page lists workflows and features that have been removed or replaced. If a familiar step has moved or disappeared, the replacement is described here.

## What Changed

### 1. DocuSign — removed

DocuSign was used for term sheets, master commitments, funding notices, and batch self-certification.

DocuSign has been replaced by **Adobe Sign** and **ZohoSign**. New signatures use one of those two. Older signed documents still open. If your organization was set up only for DocuSign, switch to Adobe Sign or ZohoSign. Contact support if that change is not in place yet.

### 2. Older file storage — replaced

Older files were stored outside the current file store. Those files still open. New files are stored in the platform. You do not need to move old files yourself.

### 3. Older notifications — replaced

Notifications used to appear only when you refreshed or returned to a list. They now arrive as events happen, and you also receive email for the same events. That includes funding approvals, term sheet changes, finished batch verification, completed signatures, and settlement.

### 4. Data room — replaced

The current data room is the one to use. It includes:

* Folders inside each data room
* A secure file drop that can bring in a zip and unpack it
* Access by organization, so you can control who sees a room, a folder, or a document
* Feedback counts on documents
* Download of several documents as one zip
* A history of uploads, downloads, and access changes

### 5. Batch verification — changed

Only a verification agent could certify a batch. The issuer had to wait for that review.

The issuer now has two choices:

* **Self Certify** — Certify the batch yourself with Adobe Sign or ZohoSign. The loans are marked **Self Certify (Data Only)**.
* **Submit to Verification Agent** — Send the batch to a third-party verification agent.

Use self-certification when a third-party review is not required.

### 6. Where NFTs are minted — changed

NFT minting used to sit inside the verification agent’s review.

Minting is now in **Certificates**. Issuers use **View NFT** and **Mint NFT** there. Batch Verification is only for verification.

### 7. Who can share a pool — expanded

Only the issuer could share a pool, and an underwriter / facility agent could not pass it to investors.

The issuer can still share with underwriters / facility agents and investors. An underwriter / facility agent can also share an accepted pool with investors.


## Impact on Existing Users

You do not need to re-upload older files. They still open. New uploads are stored in the platform.

If you still expect a DocuSign window, use Adobe Sign or ZohoSign instead. Contact support if your organization has not been switched.

Issuers who always waited for a verification agent can now self-certify when a third-party review is not required. Mint NFTs from **Certificates** after the batch is reviewed.
