# New Features

## Overview

This document tracks new features and capabilities added to the Intain Markets platform. Check here regularly to learn about new functionality, improvements, and enhancements that can help you work more effectively. New features are documented when released, with release notes explaining new capabilities and how to use them.

## What Changed

**Credit Facility Module Enhancements** - Recent enhancements to credit facilities include automatic master commitment creation when term sheets are approved, streamlining the facility setup process. Per-lender e-signature tracking allows facility agents to sign funding notices for each lender individually, with each lender's signature status tracked separately. Enhanced token generation and distribution capabilities enable better tracking and management of drawdowns. Individual lender approval tracking allows each lender's approval status to be tracked individually, enabling flexible lender participation. Enhanced status workflows provide better visibility and control throughout the facility lifecycle.

**Enhanced Status Tracking** - Improvements to status tracking include comprehensive status history showing all changes with who changed what and when. Detailed action tracking records all actions with complete details, providing full visibility. Complete audit trails ensure complete accountability and compliance. Status qualifiers provide additional context about item states. Enhanced visibility improves understanding of status changes and workflow progression.

**Improved E-Signature Integration** - E-signature improvements include full support for electronic signatures across all document types. Per-lender signing allows facility agents to sign funding notices separately for each lender. Enhanced signature tracking provides better tracking of signature completion and status. Better signature visibility improves understanding of who has signed and when. Improved workflow integration enhances signature processes throughout the platform.
