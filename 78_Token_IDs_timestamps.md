# Token IDs and Timestamps

## Overview

Tokens created for funding notices have unique contract addresses and timestamps. Each token has a unique contract address, and all token events are timestamped.

## Token Creation and Identification

**Contract Address:**
- Each funding notice generates a unique contract address
- Links to blockchain records for verification
- Permanent and immutable

**Token Distribution:**
- Tokens allocated to lenders based on participation percentage
- Each lender receives their allocated amount
- Individual lender allocations tracked separately

**Token Generation Timestamps:**
- Records when tokens were created
- Records blockchain transaction hash
- Records total amount created

## Per-Lender Token Tracking

**Individual Lender Allocations:**
- tokensAllocated shows amount allocated
- Participation percentage determines allocation
- Commitment amount shows lender's commitment
- Lender organization identified

**Lender Token Status:**
- E-signature status: pending or completed
- Fund transfer status: pending or transferred
- Approval status tracked individually

**Timestamps Per Lender:**
- E-signature completion timestamp
- Fund transfer confirmation timestamp
- Status change timestamps

## Blockchain Integration

**Avalanche C-Chain:**
- Tokens created on Avalanche C-Chain
- Contract addresses link to blockchain records
- Transaction hashes enable verification

## Where Token Information Appears

**Funding Notice Details:**
- Contract address
- Token distribution with lender allocations
- Generation timestamps

**Token Distribution:**
- Each lender's allocated amount
- Individual lender status
- E-signature and transfer status

**Audit Trail:**
- Token activities recorded in status history
- Complete timeline of token events
- Blockchain transaction references

## Important Notes

**Unique Contract Addresses** - Each funding notice has a unique contract address. Permanent and immutable.

**Timestamping** - All token events timestamped: creation, distribution, e-signatures, transfers.

**Audit Trail** - Token IDs and timestamps create complete audit trails.

**Blockchain Verification** - Contract addresses link to blockchain records for independent verification.

**Permanent Records** - Token information is permanent. Contract addresses and transaction hashes remain accurate.
