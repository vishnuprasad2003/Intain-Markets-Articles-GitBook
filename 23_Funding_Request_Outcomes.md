# Funding Request Outcomes

## Overview

When a facility agent reviews a funding request, there are three possible outcomes: Approval, Rejection, or Changes Requested. Understanding these outcomes helps borrowers know what to expect, how to proceed, and what happens next in the funding process. Each outcome has different implications for your workflow and next steps, and understanding them helps you navigate the funding request process effectively.

![Funding Request Review - FA](imagesByMdFilesFolder/23/review_funding_request_FAReview.png)

## Possible Outcomes

After you submit a funding request, the facility agent reviews it and makes a decision. There are three possible outcomes: **Approved** - your request meets all requirements and is approved, **Rejected** - your request doesn't meet requirements and is declined, or **Changes Requested** - your request needs modifications before it can be approved. Understanding these outcomes helps you know what to expect and how to proceed.

## What Each Outcome Means

**Approved Outcome** means your funding request meets all requirements, and the facility agent has approved it. A funding notice is automatically created, request status changes to "APPROVED," the funding notice is sent to lenders for review, and you receive notification of approval. You can monitor funding notice progress, approve token transfer when ready, wait for lender approval, and track status updates. After approval, lenders review the funding notice, lenders approve or reject the drawdown, and after lender approval, funds are transferred to you. This outcome means your request has been accepted and the drawdown process can proceed.

**Rejected Outcome** means your funding request doesn't meet requirements, and the facility agent has rejected it. Request status changes to "REJECTED," a rejection reason is provided, you receive notification of rejection, and no funding notice is created. You can review the rejection reason carefully, understand why it was rejected, address issues if possible, and create a new funding request with corrections. You cannot resubmit the same request—you must create a new funding request if you want to try again, and the new request should address the rejection reasons. This outcome means your request has been declined and cannot proceed further.

**Changes Requested Outcome** means the facility agent needs modifications before approval. Request status changes to "CHANGES_REQUESTED," the request becomes editable again, you can make modifications, and you can resubmit when changes are complete. You should read the change request carefully, understand what specific modifications are needed, make all requested changes thoroughly, address all requested items, review your changes before resubmitting, and resubmit when complete. After making changes and resubmitting, the request goes back to FAReview status for another review. This outcome means your request needs improvements but can proceed after changes are made.

## Next Steps for Users

**If Your Request Is Approved** - Monitor the funding notice progress as it moves through lender review. Approve token transfer when ready if required. Wait for lender approval and track status updates. Prepare to receive funds after lender approval and fund transfer confirmation. Track the funding notice through token generation, borrower approval, lender review, and fund transfer. Ensure you're ready to receive funds when lenders confirm transfers.

**If Your Request Is Rejected** - Review the rejection reason carefully to understand why it was rejected. Address the issues identified in the rejection reason. Create a new funding request that addresses all rejection reasons. Ensure the new request complies with facility rules and has sufficient documentation. Submit the new request and go through the review process again. Learn from the rejection to improve future requests.

**If Changes Are Requested** - Read the change request carefully to understand what modifications are needed. Make all requested changes thoroughly and address all requested items. Review your changes before resubmitting to ensure everything is complete. Resubmit the request when changes are complete, and it will go back to facility agent review. Be thorough in addressing all requested changes to avoid additional change requests.

Understanding funding request outcomes helps you know what to expect after submission, understand how to proceed based on the outcome, take appropriate next steps to move your funding request forward, and work effectively within the funding request process.
