# Term Sheet Workflow

The term sheet is the first step in creating a credit facility. The borrower proposes terms, signs via Adobe Sign, and submits to the facility agent for approval.

## Borrower: Create and Submit

1. **Credit Facility → Term Sheet Setup** (top right) → **Create Via Wizard**
2. Fill in: **Requested Commitment Amount**, **Advance Rate**, **Pricing Index** (e.g. SOFR), **Margin**, or **Fixed Rate**, **Maturity Date**, **Drawdown Frequency**, **Covenant Template**
3. Upload required documents: **Collateral Profile**, **Financial Statements**, **KYC Documents**, **Collateral Data**
4. Click **Create Draft** → status → **Draft**
5. Sign via Adobe Sign → status → **Borrower signed**
6. **Submit to FA** popup → click **Submit** → status → **In review (facility agent)**

> If you close the submit popup, the action column shows **Submit Term Sheet** — click it when ready.

## Facility Agent: Review and Decide

1. **Credit Facility → Set-up tab → Review Term Sheet**
2. Choose:

| Decision | Status after | What happens |
|---|---|---|
| **Approve** | Accepted | Master commitment created automatically; borrower notified |
| **Reject** | Rejected (final) | Borrower must create a new term sheet |
| **Request Changes** | Changes Requested | Borrower edits, re-signs, and resubmits |

![Review Term Sheet - FA](.gitbook/assets/review_term_sheet_FA.png)

## Borrower: Respond to Changes Requested

1. Status shows **Changes Requested** → action column shows **Edit Term Sheet**
2. Read the facility agent's comments → **Edit Term Sheet** → make changes → **Update**
3. Adobe Sign opens → sign again → status → **Borrower signed**
4. **Submit** → status → **In review (facility agent)**

## Term Sheet Statuses

| Status | Meaning | Actions available |
|---|---|---|
| **Draft** | Created, not signed | Edit, sign |
| **Borrower signed** | Signed; ready to submit | Submit to facility agent |
| **In review (facility agent)** | Awaiting decision | View (borrower); Review (facility agent) |
| **Accepted** | Approved; master commitment created | View |
| **Rejected** | Final — cannot be resubmitted | View only |
| **Changes Requested** | Borrower must edit and resubmit | Edit, sign, resubmit |

## Key Rules

- Must be signed via Adobe Sign before submission
- No editing while status is **In review**
- Rejected term sheets are final — create a new one to try again
- Master commitment is created automatically on acceptance
