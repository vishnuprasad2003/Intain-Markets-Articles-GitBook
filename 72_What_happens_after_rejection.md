# What Happens After Rejection

Rejection closes the current item permanently. The rejected item is read-only — you cannot edit or resubmit it. To try again, create a new item.

## Rejection vs Changes Requested

| Aspect | Rejection | Changes Requested |
|---|---|---|
| Final? | Yes | No — item returns to you |
| Editable? | No | Yes |
| Submit same item again? | No — create new | Yes — edit and resubmit |
| Next records created? | None | Not yet |

## What Happens for Each Item

### Term Sheet Rejected

- Status → **Rejected**; facility agent's comments saved with the record
- No facility is created; no lenders are added
- All uploaded documents (collateral profile, financial statements, KYC) remain viewable
- **Next:** Create a new term sheet addressing the comments → sign → submit

### Funding Request Rejected

- Status → **Rejected**; reason saved on the request
- No funding notice is created; no tokens are recorded
- **Next:** Create a new funding request on the same facility with a corrected amount, date, or documents

### Pool Mandate Rejected

- That underwriter / facility agent will not structure the deal; pool is not deleted
- **Next:** Improve the pool (add/remove loans, update documents) → share with a different underwriter / facility agent or share with investors directly

### Loan Removal Request Rejected (by Issuer)

- Loan stays in the pool and in all calculations
- This protects the original item — underwriter / facility agent / investor cannot force removal

### Lender Declines a Funding Notice

- That lender's decision is recorded as **Rejected** on their portion
- Other lenders on the same notice are not affected

## Key Points

- Rejected items stay visible as read-only records with full history and documents
- The rejection reason is saved with the item — use it when preparing the next submission
- You are notified in the platform when a rejection occurs
- Admins cannot override or reopen a rejected item
