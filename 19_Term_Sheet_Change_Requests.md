# Term Sheet Change Requests

When a facility agent requests changes, the term sheet status changes to **Changes Requested**. This is not a rejection — edit, re-sign, and resubmit the same term sheet.

## Steps

1. **Credit Facility** → find term sheet with status **Changes Requested** → action shows **Edit Term Sheet**
2. Read the facility agent's comments carefully
3. Click **Edit Term Sheet** → make the requested changes (amounts, rates, maturity date, documents)
4. Click **Update** → Adobe Sign opens → sign the updated document → status → **Borrower signed**
5. **Submit to FA** popup → **Submit** → status → **In review (facility agent)**

> If you close the Submit popup, the term sheet stays **Borrower signed**. Click **Submit Term Sheet** on the dashboard when ready.

## Outcomes After Resubmission

| Decision | Status | What to do |
|---|---|---|
| **Approved** | Accepted | Master commitment created automatically |
| **Rejected** | Rejected (final) | Create a new term sheet |
| **Changes requested again** | Changes Requested | Repeat — edit, sign, resubmit |

## Key Rules

- You can only edit when status is **Changes Requested**
- Every update requires a new signature — the previous signature does not carry forward
- Must click **Submit** after signing — signing alone does not send the term sheet back
- Address all of the facility agent's comments before resubmitting
- More than one round of changes is allowed
