# Common User Questions

## Pools

**Q1. How do I create a pool?**
Pools → **Set-up Pool** (top right) → fill in name, asset class, transaction type, organisations → **Create**.
→ See [Pool Creation and Sharing](41_Pool_Creation_and_Sharing.md)

**Q2. How do I add loans to a pool?**
Asset Registry → select loans → **Map to Pool** → choose pool → confirm.
→ See [Loan Management](42_Loan_Management.md)

**Q3. What do the tick and cross icons mean on loans?**
An underwriter / facility agent or investor has requested loan removal. **Tick** = accept (loan → Removed). **Cross** = reject (loan stays).
→ See [Pool Feedback Workflow](09_Pool_Feedback_Workflow.md)

**Q4. How do I share a pool?**
Pool details → **Share** → select recipient type and organisations → set feedback/download permissions → **Share**.
→ See [Pool Sharing and Mandates](08_Pool_Sharing_and_Mandates.md)

## Loans

**Q5. How do I upload loans?**
**Imports** → select As Of Date and Asset Class → choose file → **Submit**.
→ See [Loan Management](42_Loan_Management.md)

**Q6. What is Trigger LTS?**
LTS (Loan Tape Standardization) maps your column headers to Intain standard fields. Click **Trigger LTS** → review AI-suggested matches → **Save Mapping**.
→ See [Loan Management](42_Loan_Management.md)

**Q7. When can I mint NFTs?**
After batch verification is **Reviewed**. **Certificates** → **Mint NFT** → select loans → **Mint Selected**.
→ See [Loan Management](42_Loan_Management.md)

## Credit Facilities

**Q8. How do I create a term sheet?**
**Credit Facility** → **Term Sheet Setup** → **Create via Wizard** → fill in details → **Create Draft** → sign via Adobe Sign.
→ See [Term Sheet Workflow](18_Term_Sheet_Workflow.md)

**Q9. Why can't I create a funding request?**
Two checks: (1) Master commitment must be **Active** (at least one lender approved), and (2) Facility Setup Status must be **Completed** (facility agent finished Set Up Deal).
→ See [Funding Requests](44_Funding_Requests.md)

**Q10. How do lenders see funding notices?**
After the facility agent approves the notice and e-signs for each lender individually, that lender sees the notice in their Credit Facility section.
→ See [Token Approval](45_Token_Approval.md)

**Q11. What is Confirm and Settle?**
After lenders transfer funds, they click **Confirm and Settle** to finalise. Tokens transfer to the borrower.
→ See [Funds Transfer Confirmation](31_Funds_Transfer_Confirmation.md)

## General

**Q12. How do I switch roles?**
Log out and log back in; select your role on the login screen.
→ See [Login and Navigation](03_Login_and_Navigation.md)

**Q13. Why are some buttons disabled?**
Item isn't in the right status, your role doesn't have permission, or a prerequisite step is incomplete.
→ See [Why Can't I Act](83_Why_cant_I_act.md)

**Q14. How do I provide feedback on a pool?**
Pool details → **Feedback** section (pool-level) or **Loans tab → chat box icon** (loan-level).
→ See [Pool Feedback Workflow](09_Pool_Feedback_Workflow.md)

**Q15. Where can I see the audit trail?**
**Sidebar → Activity Audit** — all actions with who, what, and when.
→ See [Who Changed What and When](76_Who_changed_what_and_when.md)

**Q16. How do I log in with Microsoft SSO?**
Click **Sign in with Microsoft** on the login page → complete Microsoft authentication → select your role.
→ See [Login and Navigation](03_Login_and_Navigation.md)
