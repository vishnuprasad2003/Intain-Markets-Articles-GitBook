# Why Can't I Act?

Match your situation below, then follow the fix.

## Pools

| Issue | Cause | Fix |
|---|---|---|
| Can't edit pool | Pool is in **Deal** status, or you're not the issuer | Pools lock after Deal is accepted |
| Can't share pool | Pool not in Created or Preview, or no organisations assigned | Edit pool to add organisations |
| Start Deal disabled | Not all pool loans have been NFT-minted | Go to Certificates → finish minting |

## Loans

| Issue | Cause | Fix |
|---|---|---|
| Can't map loan to pool | Loan is already in a pool | Unmap it first |
| Can't mint NFTs | Batch is not Reviewed | Finish Self Certify or verification agent review first |
| Mint NFT button disabled | Batch is Pending or already Verified | Self Certify or use View NFT |

## Term Sheets

| Issue | Cause | Fix |
|---|---|---|
| Can't submit | Not signed, or required fields/documents missing | Click Create Draft → sign via Adobe Sign |
| Can't edit | Status is In review, Accepted, or Rejected | Wait for facility agent, or create a new one |

## Master Commitments

| Issue | Cause | Fix |
|---|---|---|
| Can't create funding request | Commitment not Active, or deal modelling not Completed | Lender must approve; facility agent must finish Set Up Deal |
| Can't see master commitment | Term sheet not approved yet | Wait for facility agent |

## Funding Notices

| Issue | Can't see notice (lender) | Facility agent hasn't signed for you yet — wait |
|---|---|---|
| Can't Confirm and Settle | Payment method not selected | Choose payment method during Review Funding Notice |

## General

| Issue | Cause | Fix |
|---|---|---|
| Can't see an item | Not shared with your organisation, or wrong role | Ask the issuer to share, or log in with the correct role |
| All buttons disabled | Session expired, or status doesn't allow action | Log out and sign in again; read the item's current status |
| Can see a deal but can't act | Status doesn't match your action | Investors commit on Published; confirm repayment during Repayment In Progress |

## Narrowing It Down

1. Read the item's status
2. Hover the button for the tooltip message
3. Confirm you are in the correct role
4. Confirm earlier steps are complete
5. If still stuck, contact support with the item reference and current status
