# Term Sheet Submission

## Steps

1. **Credit Facility → Term Sheet Setup** (top right) → **Create via Wizard**
2. Fill in:
   - **Requested Commitment Amount** — maximum borrowing limit
   - **Advance Rate** — share of collateral value to borrow against
   - **Pricing Index** (e.g. SOFR) + **Margin**, or **Fixed Rate**
   - **Maturity Date**
   - **Drawdown Frequency** (Monthly, Quarterly, etc.)
   - **Covenant Template**
3. Upload required documents: **Collateral Profile**, **Financial Statements**, **KYC Documents**, **Collateral Data**
4. Click **Create Draft** → Adobe Sign window opens → sign the document → status → **Borrower signed**
5. **Submit to FA** popup → **Submit** → status → **In review (facility agent)**

> If you close the Submit popup, the term sheet stays **Borrower signed**. Use **Submit Term Sheet** on the dashboard when ready.

## Outcomes

| Decision | Status | What to do |
|---|---|---|
| **Approved** | Accepted | Master commitment created automatically |
| **Rejected** | Rejected (final) | Create a new term sheet |
| **Changes Requested** | Changes Requested | Edit, re-sign, resubmit |

## Key Rules

- All required fields and documents must be complete before clicking Create Draft
- Must sign via Adobe Sign before submitting
- Cannot edit while status is **In review (facility agent)**
- Alternatively, use **Upload Signed** to upload an already-signed term sheet document
