# Feedback vs Rejection

→ Back to [What Happens After Rejection](72_What_happens_after_rejection.md)

## Core Difference

| Aspect | Changes Requested | Rejected |
|---|---|---|
| Item stays open? | Yes — edit and resubmit | No — read-only |
| Send same item again? | Yes | No — create a new item |
| Status | **Changes Requested** | **Rejected** |
| Reviewer comments saved? | Yes, per round | Yes, as rejection reason |
| Signature cleared? | Yes (term sheets must be re-signed) | N/A |
| Next records created? | Not yet | None |

## Where Each Applies

### Term Sheets (facility agent)

| Decision | Status | What to do |
|---|---|---|
| **Approve** | Accepted | Master commitment created automatically |
| **Request Changes** | Changes Requested | Edit, re-sign, resubmit |
| **Reject** | Rejected (final) | Create a new term sheet |

### Funding Requests (facility agent)

| Decision | Status | What to do |
|---|---|---|
| **Approve** | Approved | Funding notice created automatically |
| **Request Changes** | Changes Requested | Edit and resubmit |
| **Reject** | Rejected (final) | Create a new funding request |

### Pools (underwriter / facility agent / investor)

- **Feedback** — Comment on pool or loan; pool stays in its current workflow; comments can be updated
- **Mandate declined** — Issuer can re-share with another underwriter / facility agent or improve and re-share

### Loans inside a pool

- **Loan comments** — Loan stays in the pool; unread comments are flagged
- **Removal request** — Issuer accepts (loan → **Removed**, excluded from calculations) or declines (loan stays)

## Responding to Changes Requested

1. Read the reviewer's comments
2. Make the changes asked for
3. Re-sign if it is a term sheet
4. Resubmit — item returns to **In review**

## Responding to Rejection

1. Read the rejection reason
2. Create a new item
3. Address the issues in the new submission

> Rejection is final. No appeal, undo, or admin override can reopen the item.

> There is no limit to how many times changes can be requested — but if the same issues recur, discuss with the reviewer before submitting again.
