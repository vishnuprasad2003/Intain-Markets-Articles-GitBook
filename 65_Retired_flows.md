# Retired Flows

## Overview

This document tracks workflows, processes, and features that have been retired or deprecated. Understanding retired flows helps you know what's no longer available, what replaced old workflows, and how to use current features effectively. Retired features are no longer available in the platform and have typically been replaced by improved processes.

## What Changed

**Retired Workflows** - Old ways of doing things that are no longer supported have been removed. Processes that have been replaced by improved alternatives are no longer available. Features that have been removed from the platform cannot be used. Deprecated functionality that will be removed should no longer be used. Previous methods that have been replaced should be avoided.

**Replacement Features** - Retired flows are typically replaced by better methods that provide improved functionality or user experience. New processes have been developed to replace old ones. Better alternatives are available that serve the same purpose. Platform evolution has introduced new features that replace retired ones. Current documentation reflects current methods, not retired ones.

**Migration Paths** - When flows are retired, alternatives are typically provided. Release notes explain what replaced retired features. Documentation shows current methods and workflows. Migration guides explain how to transition to new methods. Support can guide you to current alternatives.

## Impact on Existing Users

**No Longer Available** - Retired features are no longer available in the platform. You cannot use old workflows or processes that have been retired. Buttons or options for retired features have been removed. Features marked as deprecated should not be used. You must use current features instead.

**Migration Required** - You may need to migrate from old methods to new ones. Migration guides explain how to transition to new methods. Support can help you adapt to current features. Documentation reflects current methods, not retired ones. Training may be available to help you learn new methods.

**Using Current Features** - Focus on using current features that replace retired ones. Current documentation shows how to use current methods. New features often provide better functionality than retired ones. Learning current methods helps you work effectively. Support can guide you to current alternatives.

**Identifying Retired Flows** - You can identify retired flows when features are no longer available, buttons or options are removed, documentation indicates features are deprecated, release notes mention retirement, or support confirms features are retired. If you're trying to use something that doesn't exist, it may have been retired.

**Finding Alternatives** - When flows are retired, check release notes for what replaced them. Review documentation for current methods and workflows. Contact support for guidance to current alternatives. Check migration guides for transition instructions. Look for new features that replace retired ones.

Understanding retired flows helps you use current platform features effectively, avoid trying to use features that no longer exist, know what replaced old workflows, migrate to current methods, and work efficiently with available features.
